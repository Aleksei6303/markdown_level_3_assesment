# Command line cheatsheet
![](https://www.differencebetween.net/wp-content/uploads/2018/01/Difference-between-Coding-and-Programming.jpg)
## Why this is helpful
My cheatsheet is helpful because if you only started learning how to code on github you don't remember all commands so you can look at this sheet which will help you to code

---
### Creating folder or file
- Use **`mkdir`** to create a *folder* (you should write the `/` symbol after name of the folder)
- Use **`touch`** to create a *file* (you should write `.txt` or `.md` after the name of the file)
---
### Delete folder or file
- Use **`rm <file>`** to delete *file*
- Use **`rm -rf <folder>`** to force delete *folder*
---
### Movement in directory
- Use **`pwd`** to see current directory
- Use **`cd <folder>`** to change directory
- Use **`cd ..`** to go back a directory
---
### List files
- Use **`ls`** to list directory files
- Use **`ls -la`** to detail file list
---
### Other command that you can not classify
```
1. Use "rmdir <name>" to remove empty folder
2. Use "cp <src> <dest>" to copy file
3. Use "mv <src> <dest>" to move or rename
4. Use "clear" to clear terminal screen
```
